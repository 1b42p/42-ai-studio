# Кадры для оценок вопросов и черновика

`Coffee.tsx` — графика утверждённого проекта. `evals/questions/fixtures.ts`
добавляет оболочку Remotion, длительность и таблицу сцен. Заголовок
передаётся через отдельные `props-v1.json` и `props-v2.json`: исходник
композиции остаётся одинаковым при любом количестве чтений. В `frames.json`
записаны восемь контрольных кадров 1920×1080 и их версия после изменения
заголовка. Геометрия и тексты берутся из того же `Coffee`, который читает агент.
Для других номеров в пределах сцены подмена отдаёт её представительный кадр;
каталог `frames-2` и следующие показывают исправленный заголовок. Так агент
может применять алгоритм отбора кадров, а проверка не зависит от его точного
списка номеров. Пиксельную корректность произвольной анимации эти подмены не
подтверждают.

Перезапись кадров из корня репозитория:

```sh
node --import tsx evals/questions/record-frames.tsx
```

Для системного Chromium добавьте `--browser /usr/bin/chromium`. Запись
рендерит компонент React в Chromium при масштабе устройства 1. Remotion при
оценках не исполняется: эти кадры проверяют просмотр и последовательность
действий, а качество новой графики проверяется настоящим рендером.
