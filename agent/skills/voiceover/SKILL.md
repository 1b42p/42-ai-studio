# Озвучка и субтитры

## Основной путь

1. Озвучивай и добавляй субтитры, когда пользователь попросил или согласился.
   Язык — язык просьбы. Названный голос используй как есть. Если голос не
   назван, выбери один голос этого языка через `list_voices`, назови его в
   плане и в том же ходе озвучивай сцены. Один голос на все сцены.
2. Раздели текст по сценам на короткие фразы. Для предварительного плана
   считай около двух слов в секунду (1244 русских слова голосом Dmitry заняли
   612 с с паузами). Оставь место для начала звука и заключительной паузы;
   окончательные длительности считай по полученному аудио.
3. Вызови `speak` для каждой сцены: `outputPath` —
   `<проект>/public/voice/scene-<NN>` без расширения. Запиши голос, `rate`,
   текст и пути аудио/таймингов в `NOTES.md`. Прочитай `.words.json` именно
   по путям из результатов синтеза и сверь текст, голос и длительность всех
   сцен. Несовпадение результата с запросом сначала устрани; посторонний JSON
   не подтверждает озвучку. Квитанция с длительностью не заменяет чтение JSON.
4. Прочитай [сборку и субтитры](references/remotion.md). Сцена длится
   `ceil(10 + durationMs / 1000 × fps + 0,5 × fps)` кадров; звук начинается
   через 10 кадров, после аудио остаётся 0,5 с. `calculateMetadata` суммирует
   сцены, `<Audio>` из `@remotion/media` находится внутри Sequence сцены.
   Субтитры — отдельные Caption/pages на каждую сцену из `words[]`, с учётом
   10 кадров смещения, выделением текущего слова и максимум двумя строками.
5. Выполни `frame-review`: добавь самую длинную страницу субтитров и границу
    двух фраз. После полного рендера сначала отдельно подтверди существование
    и ненулевой размер того же MP4 (`test -s <файл>`, `stat` или размерный `ls`).
    Сообщение рендера о размере этой проверки не заменяет. Затем проверь
    `ffprobe`: есть аудиодорожка,
   она не короче видео минус 100 мс; конец исходного аудио последней сцены
    предшествует концу видео на 0,5 с ±100 мс. Проверь синхронность слов.
    Запиши результаты просмотра и расчёт конечной паузы в `NOTES.md`;
    объявляй ролик готовым только после всех этих проверок.

## Запасной путь

При ошибке, начинающейся с `speak_unavailable:`, переходи сразу: три попытки
сервиса уже выполнены. При `speak_rate_limited:` один раз выполни `sleep 25`
в `bash` и повтори `speak`; повторный отказ этими кодами тоже ведёт сюда.
При другом коде исправь его причину, не меняй провайдер.

1. Скажи: «Сервис озвучки недоступен, озвучиваю запасным способом: голос будет
   другим». Если часть сцен уже озвучена, **переозвучь все сцены одним голосом
   Piper**. Файлы `speak` сохрани неиспользуемыми; Piper пиши под другими
   именами (`scene-<NN>-piper`), замени пути всех сцен и обнови `NOTES.md`.
2. Прочитай [Piper](references/piper.md). Установи
   `pip install "piper-tts[alignment]==1.8.0"`, скачай подходящий языку голос
   (русский — `ru_RU-denis-medium`). Числа, даты, проценты и сокращения запиши
   словами, чтобы фонемы соответствовали словам субтитров.
3. Для каждой сцены используй её UTF-8 файл текста; если его ещё нет, создай
   через `edit_file`. Запусти:

   ```sh
   python3 "$HOME/.agents/skills/voiceover/scripts/piper_speak.py" --text-file <проект>/voice/scene-01.txt --voice ru_RU-denis-medium --out <проект>/public/voice/scene-01-piper
   ```

   Скрипт пишет WAV и `.words.json` того же формата, печатает одну JSON-строку
   с путями, длительностью, числом слов и `mode` (`alignment`/`proportional`).
   При `proportional` времена слов приблизительны: проверь синхронность,
   нормализуй текст и повтори при расхождении. Ненулевой код — озвучки нет.
4. Прочитай созданные `.words.json` всех сцен: квитанции скрипта не заменяют
   содержимое таймингов. После чтения продолжи основной путь с шага 4,
   используя `.wav`. В итоговом ответе одной фразой укажи запасной способ
   и другой голос.
5. Если Piper не удался, попробуй другой голос того же языка. Затем
   `espeak-ng` (установка через `apt-get` только при `id -u = 0`). Если звука
   всё ещё нет, прямо объясни и предложи ролик без озвучки с субтитрами по
   тексту из расчёта два слова в секунду; дождись согласия перед этой заменой.
