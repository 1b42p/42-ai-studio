# Озвучка и субтитры

## Основной путь

1. Озвучивай и добавляй субтитры, когда пользователь попросил или согласился.
   Язык возьми из брифа. Названный голос передай в `speak`. Если пользователь
   делегировал выбор, возьми голос нужного языка из `list_voices` и продолжай
   в том же ходе. Если каталог недоступен или список пуст, вызови `speak`
   с `language` и без `voice`: `ru` выбирает Светлану, `en` — Ava без каталога.
   Если пользователь требует определённый голос или акцент, сообщи о замене;
   при запрете замены запроси согласие. Один голос на весь ролик.
2. Раздели текст по сценам на короткие фразы. Для предварительного плана
   считай около двух слов в секунду (1244 русских слова голосом Dmitry заняли
   612 с с паузами). Оставь место для начала звука и заключительной паузы;
   окончательные длительности считай по полученному аудио.
3. Вызови `speak` для каждой сцены: `outputPath` —
   `<проект>/public/voice/scene-<NN>` без расширения. Запиши голос, `rate`,
   текст и пути аудио/таймингов в `NOTES.md`. Прочитай `.words.json` по
   путям из ответа `speak`. Для каждой реплики сверь текст, голос, длительность
   и слова с тем же аудиофайлом; у сцен без реплик отметь намеренную паузу.
   При расхождении синтезируй заново и перепроверь. Прежде чем собирать ролик,
   добейся проверенной пары аудио + тайминги для каждой реплики.
   Если речь и паузы не укладываются в запрошенную длительность, подстрой текст,
   темп или визуальные паузы и пересчитай по результату. Для существенного
   отклонения согласуй новую длительность. Длительность запроса сохраняй отдельно
   от фактической: см. «Результат этапа» системных инструкций.
4. Прочитай [сборку и субтитры](references/remotion.md). Сцена длится
   `ceil(10 + durationMs / 1000 × fps + 0,5 × fps)` кадров; звук начинается
   через 10 кадров, после аудио остаётся 0,5 с. `calculateMetadata` суммирует
   сцены, `<Audio>` из `@remotion/media` находится внутри Sequence сцены.
   Субтитры — отдельные Caption/pages на каждую сцену из `words[]`, с учётом
   10 кадров смещения, выделением текущего слова и максимум двумя строками.
5. Выполни `frame-review`: добавь самую длинную страницу субтитров и границу
   двух фраз. После экспорта (черновик или финал) проверь тот же MP4 по
   [сборке и субтитрам](references/remotion.md). Одна аудиодорожка в метаданных
   не доказывает покрытие: сопоставь реплики, интервалы и подключённые аудиофайлы.
   Запиши доказательства и намеренные паузы в `NOTES.md`.

## Запасной путь

При `speak_voice_not_found` или `speak_text_not_readable` сначала исправь язык
голоса или нормализуй текст. Если проблемы с выбранным голосом остаются,
попробуй стандартный `speak` нужного языка без `voice`, если замена допустима.
Если стандартный голос тоже не покрывает реплики, используй Piper.
При `speak_unavailable` переходи на Piper; при `speak_rate_limited` подожди 25 с,
повтори `speak` один раз и используй Piper при повторном отказе. Если сам `speak`
не может выбрать голос без каталога (`voices_unavailable`), бери Piper нужного
языка, а не русский голос по умолчанию для другого языка. Остальные ошибки
исправляй по их причине.

1. Назови причину и предупреди, что голос будет другим. При смене голоса
   переозвучь все сцены одним новым голосом. Для запасного способа — **одним голосом
   Piper**. Файлы `speak` сохрани неиспользуемыми; Piper пиши под другими
   именами (`scene-<NN>-piper`), замени пути всех сцен и обнови `NOTES.md`.
2. Прочитай [Piper](references/piper.md). Установи
   `pip install "piper-tts[alignment]==1.8.0"`, скачай подходящий языку голос
   (русский — `ru_RU-denis-medium`, английский — `en_US-lessac-medium`). Числа, даты, проценты и сокращения запиши
   словами, чтобы фонемы соответствовали словам субтитров.
3. Для каждой сцены используй её UTF-8 файл текста; если его ещё нет, создай
   через `edit_file`. Запусти:

   ```sh
   python3 "$HOME/.agents/skills/voiceover/scripts/piper_speak.py" --text-file <проект>/voice/scene-01.txt --voice ru_RU-denis-medium --out <проект>/public/voice/scene-01-piper
   ```

   Скрипт пишет WAV и `.words.json` того же формата, печатает одну JSON-строку
   с путями, длительностью, числом слов и `mode` (`alignment`/`proportional`).
   При `proportional` времена слов приблизительны: проверь синхронность,
   нормализуй текст и повтори при расхождении. Ненулевой код — озвучки нет.
4. Прочитай созданные `.words.json` всех сцен: квитанции скрипта не заменяют
   содержимое таймингов. После чтения продолжи основной путь с шага 4,
   используя `.wav`. В итоговом ответе назови причину замены и фактический
   голос: «Выбранный голос был недоступен, поэтому использован [голос]».
5. Если Piper не удался, попробуй другой голос того же языка. Если реплики
   всё ещё не покрыты, объясни, что не получилось, и предложи ролик без озвучки
   с субтитрами по тексту из расчёта два слова в секунду; дождись согласия.
