# Piper в песочнице

Перед установкой прочитай `sandbox-environment`. Python 3.12 и pip уже есть.
Свободное место проверь `df -h /workspace`; пакеты идут из PyPI, модели —
из Hugging Face (оба хоста доступны на ограниченной сети Daytona).

```sh
pip install "piper-tts[alignment]==1.8.0"
python3 -m piper.download_voices ru_RU-denis-medium --data-dir "$HOME/.cache/piper"
```

Модель и её `.onnx.json` должны лежать рядом; повторно не скачивай, если оба
файла есть. Для другого языка посмотри список без аргументов:
`python3 -m piper.download_voices`. Русские medium: `denis`, `dmitri`,
`irina`, `ruslan` с префиксом `ru_RU-` и суффиксом `-medium`.

## Скрипт

`$HOME/.agents/skills/voiceover/scripts/piper_speak.py` принимает:

| Аргумент | Значение |
| --- | --- |
| `--text-file` | UTF-8 текст сцены, числа и сокращения словами |
| `--voice` | Имя скачанного голоса, например `ru_RU-denis-medium` |
| `--out` | Путь без расширения; родительский каталог создаётся |
| `--data-dir` | По умолчанию `$HOME/.cache/piper` |
| `--threads` | Положительное целое, по умолчанию вывод `sandbox-vcpu` |
| `--sentence-silence` | Пауза между предложениями, по умолчанию 0,25 с |
| `--length-scale` | Положительное число; больше — медленнее |

Скрипт устанавливает `intra_op_num_threads` равным квоте vCPU,
`inter_op_num_threads = 1`, подменяя фабрику `onnxruntime.SessionOptions`
**до** `PiperVoice.load`. Указание только OMP-переменных этого не заменяет;
`nproc` показывает ядра хоста, не квоту. И загрузка, и `voice.synthesize`
получают `include_alignments=True`. Дополнение `[alignment]` ставит `onnx`,
который нужен для патча модели в памяти.

На образе песочницы (2 vCPU, 4 ГБ) 600 русских слов дали 266,653 с звука
за 14,797 с с ограничением потоков; тот же текст без ограничения — за
130,949 с (266,142 с звука; синтез стохастический). Установка дополнения
и голоса заняла 359,48 МиБ записываемого диска: `df -h /workspace` —
8,0G / 60K до и 8,0G / 360M после (61440 → 377004032 байт занято).
Оставляй запас места для WAV и видео; кэш pip включён в этот объём.

Каждый AudioChunk содержит фонемы с `num_samples`. Сумма отсчётов групп
между фонемами-пробелами даёт время слов; BOS/EOS и пунктуация учитываются,
сдвиг куска включает длины предыдущих кусков и добавленную тишину.
Токен без букв/цифр приклеивается к предыдущему слову (в том числе тире),
знаки остаются в тексте. Если выравнивания нет или число групп не совпало,
время распределяется по числу букв в пределах куска (`proportional`).
`sentences[]` сохраняет исходные границы предложений и паузу до следующего.
`durationMs` считается по записанным отсчётам WAV; `voice` — `piper:<имя>`,
`format` — `wav`, время — миллисекунды от начала файла.

При ошибке сначала прочитай stderr: отсутствие модели требует скачивания,
отсутствие `onnx` — установки дополнения, нехватка диска — освобождения
только созданных этой задачей промежуточных файлов. Не считай успешный старый
WAV результатом неудачного нового вызова.

[голоса](https://huggingface.co/rhasspy/piper-voices),
[потоки ONNX](https://onnxruntime.ai/docs/api/python/api_summary.html).
