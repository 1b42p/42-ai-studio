# Из материала в ролик

## 1. Прочитай источник до уточнений

Путь файла возьми из подписи вложения `Attached file <путь> (<тип>)`.
Исходный файл сохраняй неизменным. Результаты чтения — в рабочей области
`source/<имя>-<расширение>/`, вне проекта Remotion: `report-pdf`, `report-xlsx`.
Для статьи по ссылке сразу переходи к разделу 3.

Загрузи `sandbox-environment`. Один раз за сессию проверь зависимости:

```sh
python3 -c 'import pdfplumber, pptx, openpyxl, charset_normalizer'
```

Если импорт не прошёл, установи закреплённые версии (PyPI доступен):

```sh
pip install pdfplumber==0.11.10 python-pptx==1.0.2 openpyxl==3.1.5 charset-normalizer==3.5.2
```

Первым используй скрипт навыка; собственный разбор пиши только после его отказа.

```sh
python3 "$HOME/.agents/skills/reading-documents/scripts/inspect_document.py" <файл> --out /workspace/source/<имя>-<расширение>
```

Опции: `[--out <каталог>] [--pages 1-20] [--max-pages 200] [--pages-png]`;
список страниц также `1,3,5-7`, только PDF. Для CSV есть `--encoding` и
`--delimiter`. При повторном запуске выбирай новый пустой `--out`.
На экране сводка до 80 строк: вид, размер, число страниц/слайдов/листов,
созданные файлы, предупреждения. Полный текст — `overview.md`, таблицы —
`tables/*.csv`, картинки — `images/`, страницы PDF с флагом — `pages/`.
Читай `overview.md` через `read_file` частями. Числа для графиков бери
только из `tables/*.csv`; текстовый пересказ не заменяет числовые данные.

## 2. Проверь полноту

Перед чтением конкретного формата прочитай [форматы](references/formats.md).
PDF без текста помечен `нет текстового слоя`: повтори с `--pages-png`,
смотри `pages/*.png` (или `.jpg`) через `read_file`; OCR в образе нет.
Короткий PDF можно просмотреть глазами: eve передаёт модели PDF до 20 МиБ.
PPTX: проверь скрытые слайды, заметки, диаграммы и картинки в группах.
XLSX: проверь все листы, скрытые листы и формулы без сохранённых значений;
пустой результат формулы не равен нулю. CSV: сверь кодировку, разделитель,
десятичную запятую, единицы и типы столбцов с исходником.
Скрытый материал предложи включить отдельно. При лимите страниц или скане
назови доступное подмножество и честно предложи ролик по нему.

`.xls`, `.ppt`, `.doc`, пароль, повреждение и слайды-картинки не читаются
полноценно: одной фразой объясни причину и предложи пересохранить в XLSX,
PPTX или PDF с текстовым слоем. LibreOffice в образе нет.
DOCX, HTML, EPUB — только запасной путь: `pip install "markitdown[docx]"`.
Перед запуском ограничь потоки ONNX Runtime числом `sandbox-vcpu` по
`sandbox-environment`; способ — в [форматах](references/formats.md#запасной-путь).

## 3. Статья

Ссылку читай серверным `read_page`: песочница в веб не ходит. Длинную страницу
продолжай через `offset` из `nextOffset` до конца нужного материала.
Сохрани название, URL и полный полученный текст в `source/article.md` через
`edit_file`, включая примеры кода и разметку из `content`, без пересказа.
Копируй полученный текст целиком; после записи проверь, что он не усечён.
Предел `edit_file` — 256 КиБ:
для более длинной статьи сначала сохрани сокращённый пересказ, затем полный
текст командой `bash` в отдельный файл; это исключение для большого источника.
При `read_page_*` объясни причину и предложи вставить текст или приложить файл.
Пересказ верен источнику: заголовок, 3–6 тезисов, вывод. В ответе назови статью.

## 4. Сцены

После чтения, перед сборкой, уточни неизвестные формат, длительность и голос
по инструкциям агента, даже если источник приложен; известное не переспрашивай.
Презентация: примерно один слайд — одна сцена, 2–5 строк текста;
заметки предложи как черновик озвучки, если текст не задан пользователем.
Готовые картинки скопируй в `public/` проекта, диаграммы нарисуй по данным.
Таблица: выбери график по [рецептам](references/charts.md); максимум, рост
или долю для заголовка вычисли скриптом из CSV и сохрани расчёт рядом с ним.
Длительность с озвучкой — по `durationMs` из `speak` или таймингам Piper;
без озвучки — 2 слова в секунду, минимум 3 с на сцену; назови оценку в ответе.
Названия и числа в кадре сверяй с источником. Все округления назови пользователю.
Перед полным рендером выполни `frame-review`, включая сверку графиков с таблицами.
