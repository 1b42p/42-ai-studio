# Чтение форматов

## Выход скрипта

`inspect_document.py` читает только локальные файлы. Версии из `SKILL.md`
закреплены; CSV и XLSX проходят несколько потоковых проходов, а в памяти
держатся типы столбцов и 30 строк предпросмотра. Числа не округляются:
`13 010,1` → `13010.1`, U+00A0/U+202F также разделяют тысячи.
Числовым становится столбец, в котором каждая непустая ячейка после заголовка
соответствует числу. `0012`, `8 800 555 35 35`, `1,5 млн`, `(5)` остаются
текстом; смешанный столбец сохраняется целиком. Пустоты остаются пустотами.
Суффиксы `%`, `₽`, `$`, `€` снимаются с пометкой: `25%` → `25`, не `0.25`.
Заголовки с единицами сохраняются. Даты `ДД.ММ.ГГГГ`/`ДД/ММ/ГГГГ` — русская
локаль, результат ISO. Значения дат из XLSX тоже ISO.

Исходник не меняется; выбирай пустой `--out`. Разные расширения получают
разные каталоги по умолчанию: `/workspace/source/report-pdf/` и `report-xlsx/`.
Ошибка оставляет неполные результаты: они не являются прочитанным источником.

Длинный `overview.md` читай `read_file` по диапазонам строк, продолжая с конца
предыдущего диапазона. Для длинной таблицы сначала выясни названия и типы
столбцов, затем вычисляй нужное подмножество из полного `tables/*.csv` скриптом.
Не копируй сотни тысяч строк в контекст. Сохрани выборку и расчёт в `source/`.

## PDF

`pdfplumber.open`, `Page.extract_text()`, `extract_tables()` (по линиям таблицы),
`page.images` (рамки, не готовые байты картинок). Скрипт обрезает рамку до
`page.bbox`, затем `page.crop(bbox).to_image(resolution=150).original` сохраняет
PNG в `images/p<N>-<k>.png`. Рендерит `pypdfium2`, зависимость pdfplumber.
Таблицы: `tables/p<N>-<k>.csv`; текст и предпросмотр таблиц — по страницам
«Страница N» в `overview.md`. Без текстового слоя — явная пометка.

`--pages-png` сохраняет всю страницу в `pages/<N>.png` при 100 dpi.
PNG больше 3 МиБ пересохраняется JPEG качества 85 с предупреждением.
Проверь сводку: особо большая страница и в JPEG может превышать 3 МиБ
или 8000 пикселей. Тогда сделай уменьшенную копию/фрагменты для `read_file`.
Просмотр картинки подтверждает текст глазами; автоматического OCR нет.

По умолчанию не больше 200 страниц за запуск. `--pages 1,3,5-7` выбирает
страницы в исходном порядке, `--max-pages` ограничивает число обработанных.
Если сводка говорит «прочитано 200 из 340», продолжи с `--pages 201-340`
в новом `--out`. Не заявляй, что прочитан весь файл.

Пароль pdfplumber 0.11.10 оборачивает в `PdfminerException`, внутри
`args[0]` — `PDFPasswordIncorrect`: код 3. Остальные ошибки структуры — код 2.
Подробности: [pdfplumber](https://github.com/jsvine/pdfplumber/tree/v0.11.10).

## PPTX

`Presentation.slides` — порядок показа. `slide._element.get("show")` отмечает
скрытые слайды; `slide.slide_layout.name`, заголовок и абзацы с
`paragraph.level` сохраняются в обзоре. Заметки читаются только при
`slide.has_notes_slide`: затем `notes_slide.notes_text_frame`. Обращение к
`notes_slide` без проверки создаёт пустой объект заметок в памяти.

`shape.has_table`, `shape.table.rows`, `cell.text` дают таблицы;
`shape.has_chart`, `chart.chart_type`, `chart.plots`, `plot.categories`,
`plot.series`, `series.values` — данные диаграмм; скрипт берёт числовой
OOXML-кэш рядов строками, чтобы обойти округление `float` в `series.values`.
Для точечных диаграмм сохраняются обе оси X/Y, для пузырьковых также размер.
Таблицы и диаграммы
нумеруются совместно: `tables/s<N>-<k>.csv`. Это числа источника, готовый
скриншот диаграммы не нужен для построения нового графика.
Картинки — `shape.image.blob`, расширение `shape.image.ext`; рекурсивно
обходятся `group.shapes`, поэтому картинки внутри группы не теряются.

SmartArt и встроенные объекты не превращаются в полноценные сцены.
Картинки-слайды не дают редактируемого текста; рендера PowerPoint/LibreOffice
в образе нет. Попроси PDF с текстовым слоем или выделенное содержимое.
Не считай картинку из PPTX пересказом всех элементов слайда.
Документация: [shapes](https://python-pptx.readthedocs.io/en/latest/api/shapes.html),
[slides](https://python-pptx.readthedocs.io/en/latest/api/slides.html),
[charts](https://python-pptx.readthedocs.io/en/latest/api/chart.html).

## XLSX

Два `load_workbook(..., read_only=True)` — с `data_only=True` и `False`.
Для числовых ячеек скрипт дополнительно потоково читает сырые `<v>` из XML:
openpyxl превращает их в `float`, поэтому без XML теряются длинные дроби.
Даты и типы ячеек определяет openpyxl; XML не заменяет чтение книги.
Первый даёт сохранённые значения, второй обнаруживает формулы, у которых
кэша нет. Скрипт не вычисляет Excel-формулы. `None` вместо формулы — не ноль:
попроси пересчитать и сохранить книгу в Excel/LibreOffice.
Фикстура `book-values.xlsx` действительно пересохранена LibreOffice;
`book-nocache.xlsx` собрана openpyxl и содержит две формулы без кэша.

Каждый лист сохраняется целиком в `tables/<лист>.csv`, в обзоре — имя,
`sheet_state` (в том числе hidden/veryHidden), размер, 30 строк и число
формул без значения. Имя файла: буквы/цифры, прочее `_`, до 40 знаков;
совпадения получают суффиксы `-2`, `-3`. Сверяй несколько листов по именам.

У `ReadOnlyWorksheet` нет `_charts`. Диаграммы читаются через `zipfile`
из `xl/charts/chart*.xml`: тип `*Chart`, элементы `c:f` дают диапазоны.
Значения бери из CSV листов этих диапазонов, кэш диаграммы может устареть.
При открытии PPTX/XLSX скрипт сначала проверяет ZIP: суммарный распакованный
объём не больше 512 МиБ и не больше 200 размеров архива. OLE-сигнатура у
расширения XLSX/PPTX означает пароль (код 3); старые XLS/PPT — код 2.
Ссылки: [read-only](https://openpyxl.readthedocs.io/en/stable/optimized.html),
[load_workbook](https://openpyxl.readthedocs.io/en/stable/api/openpyxl.reader.excel.html).

## CSV русского Excel

Сначала BOM → `utf-8-sig`, затем строгий UTF-8, затем `charset-normalizer`
с кандидатами windows-1251, koi8-r, cp866 и проверкой кириллических слов.
Короткий файл (<200 байт) даёт предупреждение об уверенности;
`--encoding windows-1251` переопределяет определение.
Автоматическое определение языка — эвристика: сверь названия глазами.

Разделитель определяется по первым 50 записям `csv.reader`, включая кавычки
и переводы строк внутри них: одинаковое число полей >1; приоритет при равенстве
`;`, табуляция, `|`, `,`. `--delimiter ';'` переопределяет выбор.
Один столбец читается без искусственного разбиения. `csv.Sniffer` и
`pandas.read_csv(sep=None)` для русского Excel не используй: запятая в
«Население, тыс.» может быть принята за разделитель вместо `;`.
Результат `tables/data.csv` — UTF-8, разделитель запятая, десятичная точка.
Кодировка/разделитель/единицы/типы и предпросмотр — в `overview.md`.
API: [charset-normalizer](https://charset-normalizer.readthedocs.io/en/latest/api.html).

## Запасной путь

Только для DOCX, HTML, EPUB: `pip install "markitdown[docx]"`.
MarkItDown не сохраняет картинки PPTX, а PDF-таблицы теряют структуру;
четыре основных формата читай штатным скриптом.
Ядро может загружать ONNX Runtime через Magika. Одних переменных OMP/MKL
недостаточно: перед созданием сессии выставь оба параметра ONNX, как у Piper
в `voiceover/scripts/piper_speak.py`:

```python
import subprocess
import onnxruntime as ort
cpus = int(subprocess.check_output(["sandbox-vcpu"], text=True))
original = ort.InferenceSession
def limited(*args, **kwargs):
    options = kwargs.pop("sess_options", None) or ort.SessionOptions()
    options.intra_op_num_threads = cpus
    options.inter_op_num_threads = cpus
    return original(*args, sess_options=options, **kwargs)
ort.InferenceSession = limited
from markitdown import MarkItDown
result = MarkItDown().convert("/workspace/source.docx")
```

Сохрани `result.text_content` в `source/`, картинки проверяй отдельно.
[MarkItDown и extras](https://github.com/microsoft/markitdown#optional-dependencies).

## Ошибка → ответ пользователю

| Причина/код | Что сказать одной фразой |
| --- | --- |
| `.xls`, `.ppt`, `.doc` / 2 | «Этот старый формат не читается; пересохраните в XLSX, PPTX или PDF с текстовым слоем». |
| Повреждение/неверное расширение / 2 | «Не удалось прочитать структуру файла; экспортируйте его заново в указанный формат». |
| Слишком большой распакованный ZIP / 2 | «Файл распаковывается в слишком большой объём; сохраните нужные листы/слайды отдельным XLSX/PPTX». |
| Пароль / 3 | «Файл защищён паролем; приложите копию без пароля». |
| Нет текстового слоя / 0 с предупреждением | «Это скан; могу прочитать выбранные страницы глазами либо нужен PDF с текстом». |
| Формулы без кэша / 0 с предупреждением | «Пересчитайте и сохраните книгу в Excel/LibreOffice, сейчас у формул нет значений». |
| Неверный текст CSV | «Уточните кодировку; повторю чтение с явным --encoding». |
| `read_page_*` | «Статья не открылась: <причина ответа>; вставьте текст или приложите файл». |
