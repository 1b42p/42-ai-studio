# Из таблицы в график Remotion

## Выбери данные и вид

Сначала прочитай `tables/*.csv`. Вычисли скриптом максимум, рост
`(последнее / первое - 1) * 100` (при ненулевой базе) или долю
`значение / сумма`. Сохрани исходные значения, единицы, формулу и результат
в `source/`, проверь заголовок сцены по расчёту. Пустоты не заменяй нулями.
Для точных десятичных расчётов используй Python `decimal.Decimal`.

| Форма данных | Вид |
| --- | --- |
| Значение во времени | Линия, даты по порядку |
| Категории | Столбцы, ось от нуля |
| Два ряда по категориям | Сгруппированные столбцы с общей шкалой |
| Неотрицательные доли целого | Кольцо, сумма >0; отрицательные значения требуют другого вида |
| Один ключевой показатель | Счётчик с единицей |

Не больше 12 категорий: оставшиеся объедини в «Прочее», сохрани расчёт суммы.
При 9:16 замени вертикальные столбцы горизонтальными полосами.
Не своди несовместимые единицы к общей оси. Для отрицательных значений
нулевая линия проходит внутри области графика; высоты считаются от неё.

## Статические данные

Включай данные в проект: массив в модуле или `data.json` с импортом
`import data from "./data.json"`. В шаблоне `moduleResolution: "bundler"`
это работает без правок `tsconfig.json`. Во время рендера сеть не нужна.
[`calculateMetadata`](https://www.remotion.dev/docs/data-fetching.md) нужен,
когда данные действительно приходят извне, а не для локального CSV.
Изменения проекта делай через `edit_file`; новую композицию пиши под задачу.

## Кадр управляет анимацией

Используй `useCurrentFrame()`, `interpolate`, `spring` из Remotion;
CSS `transition`/`animation` не работают при покадровом рендере.
Секунды переводи в кадры через `fps` из `useVideoConfig()`.
Размечай самостоятельные редактируемые элементы по `remotion-markup` и
`remotion-interactivity/timeline-structure.md`, без готовых компонентов сцен.

## Столбцы

Для положительных значений найди верхнюю границу: порядок
`10 ** floor(log10(maxValue))`, затем ближайший верхний множитель 1, 2, 5, 10.
При maxValue=0 выбери верхнюю границу 1. Это округление шкалы, не данных.
Высота = `value / axisMax * plotHeight`; подпись показывает исходное значение.
Запаздывание каждого столбца, конечная высота ограничена:

```tsx
const frame = useCurrentFrame();
const {fps} = useVideoConfig();
const height = interpolate(frame - index * 0.08 * fps,
  [0, 0.7 * fps], [0, value / axisMax * plotHeight],
  {extrapolateLeft: "clamp", extrapolateRight: "clamp"});
```

В сгруппированных столбцах оба ряда используют одну шкалу и легенду;
цвет не должен быть единственным способом различать значения.
Подписи над столбцами оставь неподвижными, пока меняется только высота.

## Линия

Преобразуй даты и значения в координаты внутри области графика,
построй SVG `M x y L x y…`. Пропуски разрывают линию, не соединяют нули.
[`evolvePath`](https://www.remotion.dev/docs/paths/evolve-path.md)
из `@remotion/paths` даёт свойства штриха:

```tsx
import {evolvePath} from "@remotion/paths";
const progress = interpolate(frame, [0, fps], [0, 1],
  {extrapolateLeft: "clamp", extrapolateRight: "clamp"});
const stroke = evolvePath(progress, path);
// На SVG path: d={path}, fill="none", strokeDasharray={stroke.strokeDasharray},
// strokeDashoffset={stroke.strokeDashoffset}; точки и значения — отдельные элементы.
```

## Кольцо

[`makePie`](https://www.remotion.dev/docs/shapes/make-pie.md) из
`@remotion/shapes` возвращает путь сектора. Нарисуй сектора, повёрнутые на
сумму предыдущих долей вокруг `(radius, radius)`, поверх — круг фона,
создающий отверстие. Все сектора используют один progress кадра.

```tsx
import {makePie} from "@remotion/shapes";
const progress = interpolate(frame, [0, fps], [0, 1],
  {extrapolateLeft: "clamp", extrapolateRight: "clamp"});
const {path} = makePie({radius: 180, progress: share * progress});
// SVG path вращается вокруг 180 180 на accumulatedShare * 360 градусов.
```

Подписи вынеси в легенду. Если доли округлены, назови округление пользователю;
геометрию строй по точным долям, а не по округлённым процентам.

## Счётчик и подписи

```tsx
const current = interpolate(frame, [0, fps], [0, value],
  {extrapolateLeft: "clamp", extrapolateRight: "clamp"});
const label = new Intl.NumberFormat("ru-RU", {
  maximumFractionDigits: sourceFractionDigits,
}).format(current);
```

Промежуточное значение — эффект, последняя подпись совпадает с источником.
Большие числа за пределами точности JS Number сохраняй строками и показывай
точную конечную подпись отдельно от числовой анимации.
Единицы «тыс.», «млн», валюта и проценты остаются явными в подписи/заголовке оси.

Длинные названия переноси по словам, используя `measureText` для проверки
ширины строки. [`fitText`](https://www.remotion.dev/docs/layout-utils/fit-text.md)
из `@remotion/layout-utils` подбирает размер для заданной ширины:

```tsx
import {fitText, measureText} from "@remotion/layout-utils";
const {fontSize} = fitText({text: label, withinWidth: labelWidth,
  fontFamily, fontWeight: "bold"});
const measured = measureText({text: label, fontFamily, fontSize});
// Если размер ниже минимума, перенеси слова или сократи число категорий.
```

Загрузи выбранный шрифт до измерения. Безопасные поля и минимальные размеры —
в `remotion-create/video-layout.md`: для ширины 1080 отступы 80 по бокам,
100 сверху/снизу, заголовок около 84 px, важный текст от 44 px;
масштабируй вместе с шириной композиции. Не уменьшай текст ради 12 категорий:
разбей на сцены, если подписи не помещаются.

## Проверка

По `frame-review` включи кандидатов на 25 %, 85 % сцены и последний кадр.
Проверь и фактическую границу завершения анимации: 85 % не гарантирует финал.
Общий лимит 4–8 кадров за проход сохраняется; при большом числе графиков
упрости сцены, чтобы известные риски вошли в выборку.
Сверь подписи и окончательные значения с CSV, читаемость легенды, нулевую ось,
безопасные поля и отсутствие наложений. На 9:16 края полос и длинные названия
видны целиком. Запиши проверенные числа и кадры в `NOTES.md` до полного рендера.
Если нужна дополнительная документация, читай `read_page` по
`https://www.remotion.dev/docs/<страница>.md`.
