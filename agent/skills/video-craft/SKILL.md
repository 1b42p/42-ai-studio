# Ролик: замысел и структура

Этот навык решает, **что** за ролик и как он держит внимание. Технические
детали композиции — в `remotion-create`, `remotion-markup` и `video-layout`.

## 1. Обещание

Сформулируй одной строкой, что зритель получит за время просмотра: эмоцию,
действие или знание. Всё, что не служит этой строке, в ролик не попадает.

В план добавь одной строкой жанр и обещание; длительность и площадку (лента,
сайт, экран презентации) назови там же, если они не заданы просьбой. Площадка
решает формат и темп: вертикаль смотрят коротко и без звука, горизонталь
допускает паузы и подписи.

**Готово, когда** жанр и обещание названы в плане одной строкой.

## 2. Жанр задаёт биты

У каждого жанра своя последовательность. Держи 3–5 битов: больше не
удерживается в коротком ролике.

| Жанр | Биты | Длина |
| --- | --- | --- |
| Промо, реклама | крючок → желание → продукт → доказательство → призыв | 15–45 с |
| Объяснение, инструкция | вопрос → шаги по одному → итог | 30–90 с |
| Поздравление | обращение → личная строка → пожелание → подпись | 10–30 с |
| Тизер, анонс | интрига → поворот → дата или призыв | 10–20 с |
| История, соцсети | момент → напряжение → развязка | 15–40 с |
| Новость, отчёт | факт → числа → контекст → вывод | 30–60 с |
| Итоги, подборка | хронология → ключевые точки → финал | 20–60 с |
| Песня, клип | ритм и текст на бит, повтор припева | по треку |

Крючок — первое, что видит зритель. В промо и соцсетях он занимает первые
три секунды и сразу показывает предмет или обещание. В объяснении крючок —
сам вопрос, без разгона.

**Готово, когда** биты записаны с длительностью каждого в план или в `NOTES.md`.

## 3. Сцена и текст

В каждой сцене один фокус: предмет, число, лицо или одна мысль. Фон, подпись
и движение поддерживают фокус, а не спорят с ним.

Бюджет текста на кадр:

- заголовок — до семи слов;
- пояснение — до двенадцати слов;
- не больше двух уровней текста в кадре.

Время на прочтение — около 0,3 секунды на слово, но не меньше 12 кадров
даже для короткой строки. Длинный текст разбей на два кадра, а не уменьшай.

Иерархия: один крупный элемент, один средний, остальное — служебное. Контраст
сильнее количества: спокойный фон и одна яркая мысль читаются лучше пёстрой
раскладки.

**Готово, когда** на каждую сцену записан фокус и текст в пределах бюджета.

## 4. Ритм

Смена кадра каждые 2,5–4 секунды для короткого ролика и 4–7 секунд для
объяснения. Внутри сцены что-то меняется раз в 2–3 секунды: движение,
цвет, подпись, масштаб.

Пауза — тоже приём: сцена без движения перед важной мыслью делает её громче.
Ритм не должен быть ровным метрономом; чередуй плотные и спокойные сцены.

Переходы — по смыслу. Резкая смена для поворота, плавная для продолжения.
Держи переходы в 8–15 кадрах; длиннее — только осознанно.

**Готово, когда** у каждой сцены есть длительность, а у каждого перехода —
причина.

## 5. Движение

Вход элемента — 8–15 кадров, выход — короче. Движение показывает, откуда
пришёл элемент и куда уходит; случайные направления читаются как шум.

Анимация заканчивается в конечном состоянии и не продолжается за пределами
своего интервала. Масштаб, прозрачность и сдвиг держи в разумных пределах:
увеличение больше 1,3× и сдвиг больше трети кадра выглядят как дефект.

Движение поддерживает смысл: число растёт — счётчик, список — появление
по одному, акцент — короткий импульс. Эффект без смысла убери.

**Готово, когда** у каждого движения есть интервал и назначение.

## 6. Звук

Реши и назови в плане: голос, музыка или тишина. Тишина — полноценный выбор
для короткого промо и текстовой истории.

Голос ведёт, музыка поддерживает. Под речью музыка тише; без речи — ровный
фон без резких пиков. Музыка не спорит с темпом сцен: на повороте либо
совпадает с ударом, либо уходит на паузу.

**Готово, когда** решение по звуку записано и не меняется по ходу без причины.

## 7. Проверка замысла

Перед композицией пройди пять вопросов:

- первые три секунды понятны без звука;
- в каждой сцене один фокус;
- текст читается за время показа;
- у каждого движения есть смысл;
- финал отвечает на обещание из плана.

Отрицательные ответы исправляй в сценарии, а не в готовом видео.

**Готово, когда** все пять ответов положительные и план обновлён.
