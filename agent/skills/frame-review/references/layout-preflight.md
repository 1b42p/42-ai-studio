# Проверка текста до рендера

До первого набора кадров возьми размер композиции, fps и итоговое число
кадров из кода. Возьми размеры шрифтов и прямоугольники важного текста
из вёрстки. Для многострочного текста используй высоту всего блока,
для субтитров — самой длинной страницы. Если позиция меняется, проверь
крайние положения, в которых текст должен уже читаться.

Начни с безопасной зоны. В 1920×1080 она начинается в точке `(143, 178)`
и заканчивается перед правым и нижним полем такой же ширины и высоты.
Заголовок — от 150 px, важный текст и субтитры — от 79 px. Если строка не
помещается, сначала сократи текст или выдели ему больше ширины, а не
уменьшай кегль. При проектировании не заполняй весь доступный прямоугольник:
оставь место на переносы и разную ширину букв.
Если текст и персонаж показаны одновременно, сразу выдели им непересекающиеся
колонки и отдельную полосу для субтитров, как в [примере сцены](reach-scene.tsx).
Для фигуры бери её максимальные границы во всех фазах действия, включая
кисти и стопы; проверь, что эти границы не пересекают текст. Не увеличивай
кегль, пока заголовку не выделено достаточно места.

Сохрани значения реальной композиции в `out/layout.json`. Пример записи
для двух прямоугольников (в пикселях от верхнего левого угла):

```json
{
  "width": 1920,
  "height": 1080,
  "fps": 30,
  "durationInFrames": 900,
  "targetSeconds": 30,
  "text": [
    {"label": "Заголовок", "group": "сцена 1", "kind": "headline", "fontSize": 152, "x": 160, "y": 200, "width": 890, "height": 330},
    {"label": "Субтитры", "group": "сцена 1", "kind": "body", "fontSize": 80, "x": 184, "y": 710, "width": 1552, "height": 185}
  ],
  "protected": [
    {"label": "Персонаж во всех позах", "group": "сцена 1", "x": 1160, "y": 182, "width": 600, "height": 504}
  ]
}
```

Присвой одинаковый `group` одновременно видимым прямоугольникам. Сравниваются
тексты между собой и с защищёнными объектами (`protected`) только внутри
группы; разные сцены и несовместимые состояния не сравниваются.

```sh
python3 "$HOME/.agents/skills/frame-review/scripts/check-layout.py" out/layout.json
```

Код `1`: сначала исправь перечисленные пересечения, размеры, поля или длительность,
затем обнови файл из композиции. Код `2`: исправь входные данные. Для
заданной длительности `targetSeconds` использует допуск `toleranceSeconds`
(одна секунда по умолчанию). Если не хватает кадров, добавь осмысленную
паузу без речи; если кадров слишком много, сократи фразу и переозвучь.
При приблизительной длительности без жёстких пределов `targetSeconds`
не задавай.

Код `0` проверяет только числа. Не подставляй желаемые метрики вместо
фактических. После рендера кадров по-прежнему проверь переносы, контраст,
реальное положение текста и позы.
