# Пересоздание примеров

Ролики создаются агентом 42 AI Studio через обычные пользовательские сессии,
с настоящей моделью и песочницей Daytona. Композиции не собираются вручную.
Для запуска нужны настроенные Postgres, S3, модель и активный ключ Daytona
в базе; `APP_TEST_MODE` выключен, `EDGE_TTS_*` не переопределены.

Запустите `npm run dev`, войдите через локальный `dev-login` и отправьте
каждую просьбу в новую сессию. На уточнения отвечайте минимально,
не меняя исходную задачу. Допустимо не больше двух попыток на пример;
сохраните лучший результат и скачайте MP4 из чата.

## Исходные просьбы

Генерация: 16–17 ноября 2026 года. `AGENT_MODEL=gpt-6.1-terra`.
Число исходных попыток: светофор — 2, реклама кофейни — 1, графики — 2.

### Как устроен светофор (`explainer`)

> Сделай объясняющий ролик на 30 секунд «Как устроен светофор»: три сцены, русская озвучка женским голосом, субтитры по словам, спокойная схематичная графика.

### Акция кофейни (`promo-vertical`)

> Сделай вертикальный рекламный ролик на 20 секунд для кофейни на углу: акция «Второй кофе в подарок по будням до 11:00», крупный текст, русская озвучка мужским голосом, субтитры.

### Выручка кофейни за полгода (`data-chart`)

> Сделай ролик на 30 секунд с анимированными графиками: выручка кофейни по месяцам 2025 года (янв 120, фев 135, мар 150, апр 142, май 168, июн 190 тыс. рублей) и доля напитков (кофе 54 %, чай 21 %, десерты 25 %). Русская озвучка, субтитры.

## Ревизия светофора

После исходного запроса владелец попросил усилить постановку: добавить
объём, движение камеры, анимацию сигналов и динамичные переходы.
Агент выполнил ревизию в той же успешной сессии и проекте:
настоящая 3D-сцена со светофором, дорогой и автомобилями, прежние
три сцены, женский русский голос и пословные субтитры.
Озвучка пересоздана тем же голосом Светланы. Результат — `explainer-v2`.
Первоначальная просьба выше сохранена дословно; фидбек не входит
в содержание ролика. Композицию и ревизию написал агент, не исполнитель.

## Завершение графиков

Агент завершил уже начатый проект в той же второй сессии: увеличил
заголовки и подписи, исправил безопасные поля, шрифт и переносы
субтитров. Счётчик `frame-review` сохранился: после третьего прохода
агент удалил необязательную надпись «100%» из центра кольца и выполнил
предусмотренную повторную проверку упрощённой версии. Исходные числа,
легенда, русская озвучка и длительность сохранены.

## Подготовка публичных файлов

Скачанные исходники сохраните как `explainer-source-v2.mp4`,
`promo-vertical-source.mp4` и `data-chart-source.mp4`.

```sh
ffmpeg -i explainer-source-v2.mp4 -r 30 -vf scale=1280:-2 \
  -c:v libx264 -profile:v high -pix_fmt yuv420p \
  -crf 24 -preset slow -c:a aac -b:a 128k \
  -movflags +faststart public/examples/explainer-v2.mp4

ffmpeg -i promo-vertical-source.mp4 -r 30 -vf scale=720:-2 \
  -c:v libx264 -profile:v high -pix_fmt yuv420p \
  -crf 24 -preset slow -c:a aac -b:a 128k \
  -movflags +faststart public/examples/promo-vertical-v1.mp4

ffmpeg -i data-chart-source.mp4 -r 30 -vf scale=1280:-2 \
  -c:v libx264 -profile:v high -pix_fmt yuv420p \
  -crf 24 -preset slow -c:a aac -b:a 128k \
  -movflags +faststart public/examples/data-chart-v1.mp4
```

Если видео превышает 8 МиБ, увеличьте `-crf`;
суммарный размер трёх MP4 не должен превышать 20 МиБ.

Выберите содержательный кадр и сохраните постер:

```sh
ffmpeg -ss 3 -i public/examples/explainer-v2.mp4 \
  -frames:v 1 -q:v 3 public/examples/explainer-v2.jpg
ffmpeg -ss 9 -i public/examples/promo-vertical-v1.mp4 \
  -frames:v 1 -q:v 3 public/examples/promo-vertical-v1.jpg
ffmpeg -ss 10 -i public/examples/data-chart-v1.mp4 \
  -frames:v 1 -q:v 3 public/examples/data-chart-v1.jpg
```

Если JPEG превышает 150 КиБ, увеличьте `-q:v`. Разрешение постера
должно совпадать с видео.

На постере рекламы видны полные условия акции, на постере графиков —
выручка всех шести месяцев.

```sh
ffprobe -v error -show_streams -show_format -of json \
  public/examples/explainer-v2.mp4
ffprobe -v trace public/examples/explainer-v2.mp4 2>&1 \
  | grep -E "type:'(moov|mdat)'"
npx tsx scripts/probe-examples.ts
```

Проверьте H.264 High, `yuv420p`, AAC, 30 к/с, размеры 1280×720
или 720×1280 и расположение `moov` перед `mdat`. Длительность
горизонтальных примеров — 25–45 секунд, вертикального — 15–30 секунд.
Посмотрите каждый ролик целиком со звуком: читаемость кириллицы,
согласованность голоса и субтитров и соответствие исходной просьбе.

Внесите записи в `lib/examples.json`; скрипт выше сверяет и записывает
размеры, длительность и число байтов по фактическим файлам. При замене
содержимого увеличивайте версию в именах MP4 и JPEG и удаляйте старые
файлы: публичные адреса кэшируются как immutable на год.
