# Материалы проверки PR #59

Архив и результаты ручного прогона для https://github.com/1b42p/42-ai-studio/pull/59. Это материалы проверки, а не выпуск приложения.

- coffee-project.zip — исходники последнего состояния Remotion-проекта (30 секунд), NOTES.md, конфигурация, package-lock.json и все 14 проверочных кадров. Зависимости node_modules и локальное окружение не включены.
- coffee-journey-draft-v1.mp4 — черновик 90 секунд, 960×540.
- coffee-journey-v1.mp4 — финал 90 секунд, 1920×1080.
- coffee-journey-v2.mp4 — финал 30 секунд, 1920×1080.
- sandbox-files.json — исходные размеры и SHA-256 файлов песочницы.
- VALIDATION.md — проверки, оценки поведения и замеры рендера.
- SHA256SUMS — контрольные суммы вложений.

Видео исходного 90-секундного прогона сохранены отдельно; src/Root.tsx в архиве содержит последнюю версию после сокращения до 30 секунд. Проверочные кадры первого прохода соответствуют 90 секундам, второго — 30 секундам.

Для работы с исходниками распакуйте архив, выполните npm ci в coffee-journey и используйте Remotion 4.0.538 с Node.js 24.
